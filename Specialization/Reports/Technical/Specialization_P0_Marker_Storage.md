# 城市存储：Property与隐藏建筑

Document Owner: Codex
Document Role: TECHNICAL_REFERENCE
Design Rule ID: PROG-004 / NET-004

Property适合持久事实，隐藏建筑仅为可撤销效果载体候选；方向、来源和多重资格必须由状态层表达。不能用存在一个建筑替代真实商路全集。读档Property通过范围由Status和历史证据记录；本次不新增建筑。

WHAT、数值与作用范围仅引用[Accepted D0001](../../Design/Specialization_v0.1_Design_Spec.md)的上述Rule IDs；技术契约见[Architecture](../../Architecture/Specialization_v0.1_Architecture.md)，不在这里复制公式/档位表。
原始研究和当时限制保留在[冻结原件](../../Historical/LegacyReports/Specialization_P0_Marker_Storage.md)；当前验证以[Status](../../Status/Specialization_P0_Status.md)为准。
