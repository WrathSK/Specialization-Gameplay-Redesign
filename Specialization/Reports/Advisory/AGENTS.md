# Advisory area guidance

Follow [root guidance](../../../AGENTS.md), [project guidance](../../AGENTS.md), [W0005 shared advisory boundaries](../../Workflow/README.md#shared-advisory-boundaries) and [R9 session-role resolution](../../Workflow/README.md#r9--session-role-resolution). Product identity or access to this directory does not assign a session role.

- An explicitly assigned Advisor may create/update only Markdown reports and topic navigation it owns, within its current user-authorized topic subdirectory. Reuse a suitable topic; create no unrelated topics or new governance files. Only explicitly authorized Primary governance work may edit this root AGENTS/README.
- Start with the exact user question/diff, relevant instructions, Authority/Status current boundaries and directly relevant complete contracts. Follow concrete symbols, callers, registrations or DB relationships; do not load all professions, reports or runtime code by default.
- Authorization is topic-scoped, not file-scoped. Once a review topic is explicitly authorized, independently follow relevant dependencies, historical evidence, Git history and external Civilization VI/HD/other Mod sources read-only when necessary to answer that question; no separate approval is required for each related file, module, historical report or source location. Keep reading bounded by relevance. Record significant expansions in the report's Read ledger: why current evidence is insufficient, the minimum paths/query, evidence goal and stop condition; retain source/version/context provenance. Avoid unrelated repository-wide or filesystem-wide exploration and speculative broad Workshop/backups scans. Ask for further authorization only for a genuinely separate topic, modifying protected files or an operation outside the Advisor role. This reading authorization does not relax any write, test, Git-write, deployment or game-launch restriction.
- Use the [report template and evidence guidance](README.md#reports-and-evidence). Keep facts, inferences and unknowns distinct. Review suggestions do not modify authority or authorize implementation, experiments or user tests.
- Preserve other roles' work. If report ownership, changing input or a checkpoint is unclear, stop only the affected write and report the issue. New reports remain ignored locally; follow the [existing checkpoint process](../../Workflow/README.md#advisory-and-investigation-local-checkpoints), with no Advisor Git writes.
