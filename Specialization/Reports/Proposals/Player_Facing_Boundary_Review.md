# 玩家可见的边界规则审阅

供项目负责人审阅 · 2026-11-21 · 玩法源码基线为 develop B535.562（`421e6f88`），正式设计 D0063。B536 只移出八份未启用的实验脚本。本机稳定包仍为 B528.555。

本稿只讨论当前构建新开局及同构建读档。同样看到“待确认”，玩家可能遇到三种情况。交割仍待证实，收到可靠消息后可以继续。设计已经允许继续，但这个版本还没有入口。或者游戏可能已经扣过钱、消耗过单位，再试一次会造成双份结果。本稿从玩家实际能做什么写起，供审阅现行四专业、城市身份和国内网络中会改变收益、资格、名额或城市历史的边界。诊断日志的长度等纯内部限制不在此列。

**建议先看三个场景。** 其一，新接手的第三座城市身份未明，可能让原本正常的两座城市也签不了新合同。其二，重组团队如果真的消失，混乱五回合到期仍无人能配置。其三，训练城失守后，即便地图上看不到考察团，一个无法辨认的离图间谍也足以让全国训练名额继续被占。三个场景分别涉及全国交易、本城恢复和全国单位名额，适合分开判断。

## 一座城换了主人，原来的东西还算谁的？

| 玩家遇到什么 | 现有行为，以及什么时候能继续 | 审阅性质 |
|---|---|---|
| 原城被送出，又由同一接手方直接还给我。城市编号变了 | 能把交割前后认作同一城，并确认原来的效果已经退出，才接回原专业、永久投资或原认领候选。城市改号本身可以接受。夺回一座曾有四级潜力的城市时，缺少已就职总督就只激活一级。旧路线和折扣按当前情况再算。仅看到原地出现一座城，或有一项旧效果尚未确认撤掉时，先保留历史，不重新发一份。 | 保留历史已写入设计。额外等待来自确认同一城及交割完成。过去有改号、收回投资的实机个案。开发版的和平直返、撤除失败分别有本地正常流程和人工反例。 |
| 城从我手里给甲，又从甲给乙，最后乙还我 | 设计允许同一座城恢复原历史。现有记录能证明我当初交给甲。在甲转交乙之后读档，无法仅凭乙的交还接上原记录。即使城市位置正确，也可能一直无法恢复专业。 | **已定设计，尚有实现缺口。** 本地复现到中间一手没有留下足够凭据。何种原生通知能可靠连接甲、乙仍待观察。 |
| 旧城被夷平，后来我在同一格另建城市 | 设计要求新城重新开始。正常赠城也会发出“城市移除”，所以点击夷平、找不到城、又在同址看到一座城，都不能单独证实旧城已经永久消失。目前旧址可以继续被旧记录占住，使新城无法正常登记。 | **已定设计，尚有实现缺口。** 普通赠城的移除通知有实机证据。永久毁城和同址另建的完整事件链仍待自然机会。 |
| 第一次获赠、接收自由城，或解放一座城 | 交割对象必须确实是自己。交割完成、城市已经就绪时，才冻结当时已完工的合格区域供认领。没有候选就等交割后的首个合格完工。把城解放给第三方不会给自己机会。收回已有历史的城另走原记录，不重选。 | 大原则在共同设计。这里额外区分“已经看见城”和“已经交割”。普通征服和认领读档有历史实机记录。首次和平接手和武力取得自由城的新增分支仅本地验证。 |
| 城市还没定专业，来了一个可能决定首个区域的完工通知，却认不出来源 | 能定位到这座城时，只让它的首次身份待核。两个来源矛盾或连城市也无法定位时，本次游戏会话内该玩家后续的“按首个完工自动定专业”也暂停，不能把下一条通知冒充第一条。已定专业、已冻结候选的认领仍可进行。已存下的本城错误没有靠等一回合解锁的入口。 | **保护范围比单城更大。** 两种范围都做过本地故障注入。未证明正常游戏会产生这种坏通知，也未证明跨读档能补回顺序。 |

## 商路、读档与投资

| 玩家遇到什么 | 现有行为，以及什么时候能继续 | 审阅性质 |
|---|---|---|
| 商业城与科研城之间的路线一直正常，又有第三座城正在交割 | 即使已经再次收到这条路线，只要本方还有一座城的专业归属无法确认，两类新投资仍可能一起等。已登记且确认“无专业”就足够，不要求那座城先取得专业。待交割和路线都可确认后，两类签约重新开放。 | **需要审的实际影响是跨城阻塞。** 严格签约已有设计，第三城造成的等待有真实模块本地复现。自由城征服漏登记的旧反例已修，不应再当作所有自由城都会触发。 |
| 刚读档，城市仍有原收益，网络或馆藏数据却还没准备好 | 已经生效的被动收益先保持。有了可靠数据再核算。标准化本地和外来加成合在一起时，读档初期无法拆分就暂留整体。游戏中个别来源暂时读不到，只能沿用仍有效、曾经确认过的贡献。新的交易不能凭这些旧值签。已确认接收城易主、退出或不再合格，优先处理。 | **已有明确设计，不需重定。** 文化五项本地效果和已付的发展投资加成也有同构建延迟读取的本地对照。认领、扣款、发单位并不适用“照旧发放”。 |
| 商路长期没能确认 | 投资面板在可定位时会指出一个阻塞城市，多城时显示编号最小者。一次证明超过 128 条路线或 16,384 字节报文时会拒绝整份证明，不会只取前一部分来签约。没有按等待回合数自动放行。设计要求异常持续时给出严重提示，但什么现象可以认定“已超过正常初始化”尚未确定。旧被动收益可能继续可见，新交易继续等待。 | **待界定的是何时提示异常。** 真实的路线变化和正常读档已有实机记录。没有据此认定长期停滞在正常游戏中常见。现有本地回合核对仍保留。 |
| 商业城准备签约，但最低可建层的两座建筑中有一座不能可靠报价 | 无法知道哪座最便宜，就不给该目标区域报可确认的价格。能够核实另一座的价格也不足以代表整组。市中心若有多个可建对象，会按同组最低价报价，合同加速该区域合格建筑直到下一座完工。 | 前者是局部报价保护。后者是现有目录与定价共同产生的结果，已有水磨实机合同。是否保留市中心组属于平衡审阅。 |
| 已知来源消失，或原来读不到的来源悄悄恢复了 | 有可靠失效证据，新签约立即停。若原金币效果只撤掉一部分，城市仍可能保留一部分实际收益。不会把预期撤除的目标值显示成已经生效。下一次相关核对成功后再纠正。工业来源的模板重新可读却没发通知时，现有回合核对能撤掉多余折扣。 | **只在本地模拟了漏通知、撤除失败。** 曾刻意关掉回合核对作对照，残留一直持续。没有据此断定引擎平时漏报，也没有增加新的补发机制。 |
| 已点确认，无法判定是否扣了本金、发了到期款，或消耗了开拓者 | 有确切消费或付款凭据的，沿既有记录完成可确认的后半段。只留下“准备执行”或“已调用”而不能确认实际结果时，刷新、重按、读档均不盲目再扣、再付或再升一级。受影响投资可能长期不能继续。不会拿当前国库或少了一名开拓者来猜先前交易。 | **异常保护。** 正常合同只扣、只付一次有实机记录。中途失败的阻塞有源码和本地注入，不能据此判定实机吞款。资本、发展和开拓者投资分别认自己的凭据。 |
| 已签合同后，专家撤走、断路、关键城换主，或者只收到文明灭亡消息 | 普通资格下降不取消已签合同。资本投资的商业来源城或锁定收益来源城易主，终止且不返本金。发展投资的商业来源城或目标城易主，不退款，撤加成并释放名额。确认永久毁城按对应规则办。**只有文明灭亡消息**且关键城结局不明，或签约后目标区域／建筑本身变得不合法，两者的最终处理均待定。 | 普通存续、明确易主及永久毁城后果已在 Design。保护性等待不能当作两种待定情况的终局裁定。 |

## 单位、任务与全国名额

| 玩家遇到什么 | 现有行为，以及什么时候能继续 | 审阅性质 |
|---|---|---|
| 考察团还在训练，训练城正式易主，地图上没看见团 | 原主人这张已入队、未完成的订单可以作废。若已收到出生或完成消息，则保留名额。若只有“有间谍在地图外”的总数，不能辨认其中有没有考察团，也保留全国名额。离图数归零，己方地图单位可辨认，且相关情况没有在检查途中改变，才允许另一座文化四级城接着训练。仅失去城市视野不算正式交割。 | 失城作废、确认无团才释放是刚批准的 D0063。**额外可见代价**是一个普通间谍也可能延长等待。两城、读档及顺序变化已本地验证，未观察到对应的实机交割。 |
| 外交建筑赠送单位，或只看见单位出生却没有原城训练完工的证据 | 外形、名称或所在城市相符，都不足以把单位登记为该城正式训练的考察团。已预留的订单只有出生和完工之一时也不能再开一单。该单位可能没有考察团任务按钮。 | 玩家曾看到赠送单位异常。登记条件有源码和本地测试支持，赠送过程为何选到该单位仍缺少完整实机证据。 |
| 考察团已成团，失去归档城，或莫名出现在目标城市旁边 | 失去归档城后不会向旧城写见闻，单位仍属原主人，并占全国唯一名额。设计允许免费改挂另一座己方文化城，当前版本没有重挂入口。这与上一行的空缺训练单是两个不同的问题。另有实机日志确认过单位被传送一格后任务停止，玩家同时观察到关边境和行动按钮消失。单凭两件事同回合发生，不能认定外交是原因，也不能把该单位当作死亡。 | **重新挂靠是已知缺口。** 位移是独立实机观察，原因未定。已成团记录异常且辨认不到单位时，也没有通用的“名册为空即清掉记录”操作。 |
| 考察团在外国城开始任务，或任务到期时目标资料不全 | 跳过该回合的单位可能不能开始任务。已经手动休眠并能确认状态的单位可以开始，任务结束后可仍需玩家唤醒。艺文采撷看全城有无合格作品，巡礼看选定奇观。确证失效就取消、不占见闻机会。到期证据未齐会等本回合相关更新，跨过窗口仍不能证明当时有效则停止这次结算，不用后来出现的作品倒补见闻。 | 跳过／手动休眠的区别有玩家观察。到期事实持续不可读是技术保护。不等于间谍原生必然拒绝休眠或随机失败。 |
| 已认识目标文明，但一座已揭示的城市都没有。或者已有普通间谍占槽 | 需要该文明至少一个已揭示城市作为入口。当前考察团还占用原生间谍容量，全国再叠加 Mod 自己的一团上限。首版只支持标准速度，三种任务各两回合。艺文和奇观任务可在目标市中心执行，仍检查真实作品／奇观。 | 设计只给考察团设全国一团上限，也给出了按游戏速度调整时长的公式。占用原生间谍槽是已接受的阶段限制。目前实现固定两回合，支持范围限标准速度。已揭示城市是现行进入条件。 |
| 两座工业城同回合训练同档施工队，又取消了一张尚无进度的订单 | 两城各自确有完成凭据就各发一队。另一城已消耗的完成次数能逐个对上，取消的空订单才释放。已经投入生产力或仍在队列的订单保留。若只剩全国累计数，不能把跳增的差值直接发成单位，也不能证明本城订单可以取消。归属不明可能阻止该城继续组建。 | 实机已通过计数先 1 后 2 的双城情形。取消空订单、读档后缺中间凭据有本地对照。其它顺序和迟到通知仍各自待观察。 |
| 在奇观上点施工，或一批重组团队同时出生 | 施工已预留但无法确认队伍消费或进度结算时，这次施工不能靠再点一次补发，可能留下无法再次使用的队伍。新生重组团队需要对应训练城市，多个出生与完工无法配对时暂不登记来源。 | 两类一次性保护互相独立。正常施工有实机记录。异常消费及无法配对的后果有源码依据，缺少正常实机触发证据。 |

## 混乱、项目计时与专业历史

| 玩家遇到什么 | 现有行为，以及什么时候能继续 | 审阅性质 |
|---|---|---|
| 已经清算，等满五回合，原来执行清算的团队却找不到了 | 只有绑定原事务的那一队能配置。只要它还活着并能归来，就能在满足条件后配置。若它永久消失且城仍归我，没有换队、计时救回或自动配置的入口，非食物产出及余粮的 −75% 可无限期延续。训练来源城易主不会取消另一座城的重组。 | **最需要审的单城后果。** 设计规定五回合是最低等待、战败应安全撤回。它没有把“团队永久消失就永久受罚”定成玩法。正常清算配置有实机验证。没有已核实的正常永久失队案例。 |
| 团队已经完成配置，但不能确认混乱惩罚已经撤掉 | 城市报告可以同时显示新身份已提交、旧惩罚撤除未确认。不会退回旧专业、返还潜力或再消耗一队。随后同一城市身份确实撤除成功，才清除这一条错误。 | 人工故障验证。新专业当前生效等级按通常条件计算。不能据这一反例另设“暂缓新商路收益”的规则。 |
| 一回合项目已经排在最前，后面还有一个工兵 | 认领、时代对话、工程传统研习都要求能确认当前生产目标。多项队列不自动启动计时。排到只剩该项目，或移走其余目标并能确认时，可开始完整回合。仅看不到队列不算取消，也不发奖励。认领选哪种身份、对话占哪一时代、研习消耗哪个机会，仍各自判断。 | 队列保护已在共同设计。对话和研习有玩家操作记录。共享计时不能证明所有项目特殊归属都已实测。 |
| 新建奇观时历史写入失败，此后还想做工程研习 | 后来看见一座奇观，不能据此知道是谁、在哪个时代实际完成。若完工记录未能可靠保存，依赖完整奇观历史的新研习可能持续不可用。仍能读取的旧记录不凭空作废。 | 异常保护，可能跨读档。现有代码和故障测试支持这一后果，没有证据表明普通建成奇观就会触发。 |
| 某专业的一项永久记录读不到，或读档时总督、馆藏尚未就绪 | 通常隔离受影响的一项。能凭本城可靠历史确定重建才重建。若记录已证实永久损坏，又没有可靠历史可重建，受影响的能力会明确报错并停止不安全的结算。基础城市身份也不可靠时，影响范围才扩大。学术传统或商业信誉的计龄区间如果无法确认，该段不补计。仅信誉这一项异常、其它必要事实可靠时，指定的合法商业化和新风险投资可按无信誉加成计算。已签合同仍依原条款。总督资料未知本身不等于已离任。已确认区域失效仍可先处理对应能力。 | 这些主要已写入共同设计／专业设计。读一次失败就全部归零、丢失全城收益、补算错过的历史，都不是已有的一般处理。 |
| 面板上的公式看似支持，但效果其实只开放了一部分 | 意义延展目前不发政府广场、外交区的文化追加。时代对话现阶段放大巨作旅游业绩。科研网络额外市政鼓舞在 v0.1 隔离。它们与“读档时还没拿到数据”有不同原因，单纯多等一回合不会补齐未开放部分。 | 已登记的能力范围或实现差异。审阅时可另议文案同步，不借本稿扩大能力。 |

## 哪些值得负责人现在看

- **涉及玩家长期失去操作机会。** 优先看原重组团队永久消失、一个无法辨认的离图间谍占全国名额，以及未知第三城拖住其它城市签约。审阅的是等待的影响范围和玩家能否理解原因。第三城阻塞和离图名额都有两城以上的本地对照。没有实机证据证明这三种等待实际持续了整局。
- **已有目标，继续等可靠证据。** 多手归还、同址重建、已成团后的重新挂靠已有玩法答案。若后续要增加存档凭据或修改归属，再单独提交具体选择。
- **仍缺玩法答案。** 仅有文明灭亡消息时如何处置合同、已签发展投资的目标后来变为非法、原重组队确实永久消失后是否给替代途径。网络等待达到什么证据门槛要向玩家明确报错，也仍待界定。市中心投资报价的强弱可留给平衡阶段。
- **只有故障反例。** 首建归属全失、一次性消费中断、奇观历史写入失败，以及配置后惩罚撤除未确认，先保留可诊断证据。除非看到可信的实际场景，这些反例不要求新增补偿、重试或玩家操作，也无需专门组织实机重测。
