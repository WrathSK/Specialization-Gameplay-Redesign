# 城市易主后，专业化怎么处理？

供项目负责人审阅的玩法草案，以 B528.555 为基线。适用于当前单人游戏中已启用专业化的本地玩家。第一、二节整理现行规则，第三节给出待决定的扩展。正式设计仍以 [共同规则](../../Design/Shared.md#参与资格与城市易主) 及各专业正文为准。

举一个贯穿全文的例子。你丢了一座科研四级潜力城，八回合后收回，城里没有已就职的总督。**拿回来的是原来的科研机构和四级潜力，当下生效的是一级。** 原先投入的开拓者不用再付，学术传统保留失城前的年龄，外方持有的八回合不计。以后总督到任，四级能力按当时的条件重新生效。[共同成长](../../Design/Shared.md#开拓者投资与总督门槛) · [学术传统](../../Design/Research.md)

## 一、城市到手时，先看它原来是什么城

玩家把城交易给 AI、被攻占，或城市叛为自由城，只要所有权已经转移，该城就退出原玩家的当前专业和商路网络。既有成果与合同按下一节分别处理。忠诚度下降、敌军靠近和同一存档的正常重载，本身都不构成交割。当前只由符合条件的本地玩家运行专业系统，外方照常使用游戏本身的城市和建筑。

| 交到玩家手里的城市 | 玩家得到什么，接下来能做什么 |
|---|---|
| **收回原有专业城** | 保留同一座城的专业、潜力和已确认的开拓者投资。直接按当前条件激活，不再认领。外方持有期间，连一级支持也休眠。 |
| **收回原已登记、尚未定专业的城** | 保留原来的选择。原先可从学院、剧院广场中认领，收回后仍是这两项，即使外方又建了工业区。原先须等首个合格区域完工，就继续等收回后的首次有效完工。失城前尚未完成的认领，要重新占用一个完整生产回合。 |
| **首次征服一座确实没有专业历史的 AI 城或城邦** | 只在交割时看一次已经建成的学院、剧院广场、商业中心和工业区，含认可的特色替代。只要有候选，就由玩家选其中一项完成认领，取得该专业一级潜力。即使只有一项也可以一直不选，期间没有专业等级或收益，以后新建不追加。若交割时一项都没有，则由交割后最先真正完工的合格区域定专业。 |
| **收回清算后、配置完成前丢失的城** | 丢失目标城时，未配置的资本、旧当前身份及本次绑定团队一并退出。收回时按重新取得时已完工的合格区域决定能否认领，不能续配旧资本。已积累的学术传统等独立城市历史仍在。若失城前已经成功配置，则按第一行保留配置后的新身份和潜力。 |

例：AI 的学院已建成、工业区还差一回合。你征服后只有科研可认领。若学院在交割时也没建完，两处都没有候选，之后工业区先完成就成为工业一级。两种结果取决于交割当时的事实，同一座城只判一次。[首次征服规则](../../Design/Shared.md#首次征服没有专业历史的城市) · [未认领城市收回](../../Architecture/v2/P0_E2_Plan.md#b128155--unassigned-return-checkpoint) · [资产重组例外](../../Design/Commerce.md#团队安全与重组中的征服)

## 二、城市换手时，各项成果怎么结算

| 玩家关心的东西 | 失城与收回的结果 |
|---|---|
| **科研和文化的积累** | 学术传统年龄、已完成的时代对话加成和已用的启动时代额度、已归档的文化见闻都随原城保留。外方持有期间不增长。见闻中关于现任主人自己文明的部分暂不参与收益，仍保留记录。巨作按实际馆藏位置计算，收回城市不凭旧馆藏补作品。 |
| **工业经验** | 本城学过的模板、实际完成奇观的工程经验、已完成的研习层数随城。合格工业城收回时，把目前仍在的合格建筑补入可靠模板历史。旧主人文明亲自完成奇观取得的时代信用仍归那个文明；新主人已有的文明信用只限制未来新增研习，不扣本城旧层数。其他城市经商路借用的模板和折扣按当前来源重算。 |
| **商业信誉和经营选择** | 只要同一商业机构还在，信誉冻结保留；真正退出商业身份才清零。玩家选过的商业化领域和启用顺序在易主时清空，收回后自己重选。风险投资的连续失败保护另按来源城及主人保存，新主人不继承，原主人收回仍延续的商业机构时可用自己的记录。 |
| **已经签好的投资** | 资本投资的发起商业城，或签约时锁定的那座专业来源城，任一易主，尚未结算的合同立即终止。本金不退、到期不再发钱，也不按风险失败再结算一次。签约时没有锁定来源城的，只检查发起城。发展投资的发起城或目标城易主，已付金币不退，撤掉后续建筑加速并释放名额。收回城市不能复活旧合同。 |
| **进行中的项目和任务** | 城市易主时，未完成的时代对话、工程传统研习取消本轮计时，不发奖励、不占成功额度。考察团的归档城市易主，取消未完任务，单位仍归原玩家，可免费改挂到任意己方文化专业城，无须四级。若变的是外国任务目标城，只取消这次任务，归档城照旧。 |
| **已训练的专业单位** | 施工队保持原属、训练来源和使用权。收回来源城时，自己仍存活的该城施工队重新计入该城两个名额。资产重组团队的训练城易主也不解散团队。触发解散的是它正在重组的目标城在配置前易主。 |
| **当前城市和商路收益** | 已确认失城后，原主人撤下该城的专业效果及来源、接收、签新约资格。其余城市按仍合法的路线和来源重算。单纯读不到商路时才适用已有的网络保持规则，保留值不能用来签新约。普通读档按当前所有权继续，不再认领、不重发收益。 |

例如，资本合同由商业首都发起并锁定纽约为工业来源。失去一座仅负责商路中转的城市，可以改变下一笔报价，已签的这一笔仍按原条款到期。失去纽约则立即终止这一笔，即使同回合收回也不会复活。这样玩家可以从**合同上写的两座城**直接判断风险。[商业合同](../../Design/Commerce.md#已签合同普通资格延续与易主终止) · [文化任务与见闻](../../Design/Culture.md#来源易主与重新挂靠) · [工业模板、研习与单位](../../Design/Industry.md) · [商路待确认](../../Design/Network.md#未确认不等于失效)

## 三、建议这次定下的三条规则

1. **和平得到一座外城，也给玩家同样的认领选择。** 建议把割让、获赠、自由城加入，以及解放后实际交还给玩家的城市，按第一节同样处理。第一次接手没有专业历史的城，只看交割时已经建成的合格区域；收回自己的老城，优先认原记录。例如 AI 把已有学院和剧院广场的城赠给你，你可以二选一，不必为了取得同样的机构选择而宣战。你解放一座城并交给第三方，专业归属按实际取得城市的一方处理，解放者不能替对方认领。若确有先后两次已完成的交割，各自生效。
2. **城市经几方转手，仍可认回同一座老城。** 建议玩家 → 外国甲 → 自由城或外国乙 → 玩家，与直接从甲收回采用相同继承规则。中间经过几手，都不会刷新原认领候选、对话时代额度或商业合同。前提是能确认城市一直是同一座；改名或换了城 ID 都可能是正常交割，单凭名称、地块或一次读取失败也不能接上旧账。历史暂时读不到时也不能直接按首次取得发放候选。证据不足时明确指出是哪座城、哪段转移未能确认，避免误授专业或牵连别城。
3. **旧城真正被夷平，同址重建算一座新城。** 建议以可以确认的永久毁城为界。自建新城从第一次合格建区开始；若是外方重建后才交给玩家，按首次取得外城处理。原城潜力、见闻、研习、认领候选等不传给新城，原文明已获得的奇观信用和已经兑现的收益不追回。若被毁的是未结投资的关键城，建议沿用关键城易主的终止规则。即使先失城再被夷平，也只终止一次。原玩家仍存续时，存活施工队仍可用且不占新城名额，存活考察团失去归档城可重新挂靠，绑定重组目标的团队随该事务解散。玩家刚点下“夷平”，或引擎暂时查不到城市时，都还不足以判定永久毁城。

第三条包含对旧设计明确暂缓场景的**新建议**，可单独审定。另两种相邻情况继续留待各自讨论：只有原主人灭亡的消息却没有关键城转移或毁灭证据，以及发展投资签约后目标建筑或区域本身不再合法。两者都不能直接套用本草案的毁城结算。[商业设计保留的问题](../../Design/Commerce.md#已关闭与仍未讨论的生命周期边界)

## B528 已经证明到哪一步

既有实机记录分别见过科研二级潜力城收回后保住一次投资、无总督时一级生效；两座首次征服的城市各自走「冻结候选」或「等首次完工」；商业单候选城收回后读档继续认领。这些都是具体场景的通过记录。[科研城收回](../../Status/Validation/Results/Specialization_B103_E2_Recapture_Pass.md) · [两城征服](../../Status/Validation/Results/Specialization_B111_E2_Conquest_Snapshot_Pass.md) · [认领读档](../../Status/Validation/Results/Specialization_B129_Claim_Reload_Pass.md)

B528 首次接手外城的现行入口核对征服、城市初始化和所有权转移；普通收回入口还核对直接前任是否与原失城记录相符。因此，上述证据不能覆盖首次获赠、自由城加入、多次转手或同址重建。若接受第三节，实施前需要分别确认这些场景能提供怎样的城市连续性或毁城证据。本稿没有引入新存档格式，也没有把这些分支列为实机通过。[首次征服入口](https://github.com/WrathSK/Specialization-Gameplay-Redesign/blob/8859792ce1899a0cf4e6e4fba22edfbcacd7233d/Mod/CityProgressionStore.lua#L2088-L2129) · [收回时的身份核对](https://github.com/WrathSK/Specialization-Gameplay-Redesign/blob/8859792ce1899a0cf4e6e4fba22edfbcacd7233d/Mod/CityProgressionStore.lua#L1353-L1387)
