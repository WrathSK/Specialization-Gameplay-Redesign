# B068.94 最小UI验收

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED（用户游戏验证，尚未通过）

使用现有B067正常自建城市存档即可；退出主菜单后载入新包，不需要新开局。不要用已经易主的城市测试。

1. **HUD / 城市潜力**：选一座有专业的城市，普通城市面板操作按钮上方应出现“专业城市/名城/都会/中心 · 专业 · 等级”。悬停查看专业、潜力、投资次数；用已有不同潜力城市切换比较，无需重复投资。左上世界追踪右侧出现“专业化诊断”，右上两个旧入口消失。PASS：名称/等级符合永久投资，只有一条，切城无旧数据。若失败截图全HUD（含分辨率/UI缩放），同时读“城市专业 / 潜力”。

2. **紫色目标**：选择现有移民，查看其原来合法投资区域；再选施工队，选择一个已有正在建设的合法目标城市。应出现紫色tile、不出现INVEST浮字；移动单位/切换普通单位应刷新或清除。可点一次准备确认原按钮仍为预览且确认在另一位置，无需真的消耗单位。PASS：合法范围与既有规则一致，无紫色残留；选伟人或开普通镜头没有明显覆盖。失败保留选中单位与地图的截图；单位诊断读取后写日志。

3. **诊断 / 日志**：选择城市打开诊断，依次任选“网络概况”“巨作 / 时代对话”“标准化模板”，长内容可滚动且按钮不被覆盖；再选择单位读“移民 / 施工队”。点“写入诊断日志”，保存游戏Lua.log。PASS：15主入口可读，无OFF/TEST/AUTO混入；日志有SPC_DIAGNOSTIC_REPORT_BEGIN与END及已读项。失败回传面板截图和Lua.log，无需手抄内部ID。

没有额外收益、余额或结算测试要求。上述可在同次正常游玩顺手验收。
