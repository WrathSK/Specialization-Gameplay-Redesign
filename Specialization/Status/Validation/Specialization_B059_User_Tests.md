# B059：时代对话最小实机测试

Document Owner: Codex
Build: P0-B-059.77 / modinfo77
Status: USER_GAME_TEST_REQUIRED

## 开始前

原存档优先，保持游戏内专家/宜居度/政策不变。需要Culture专业ACTIVE4城市，至少两种创作者时代的合格作品。文物时代来自自身历史标签，其它来自关联伟人；Product/Relic不计D且不受本效果。面板顶部必须B059.77。

打开Read Great Works应显示D、理论/已配置百分比、前三件creator era、原生作品Culture/Tourism、主题化建筑数。后台本来就自动应用；首次打开报告不负责启动。若“后台尚未初始化/未完成”持续，等待一次正常游戏更新再读；仍失败回传报告，不用强行继续。数据库缺失报告DIALOGUE_DATABASE_MISSING时只回传该图，可能旧存档未载入新SQL。

## 1. 普通收藏固定对照（必做，2张）

选未主题化CultureIV城，两创作者时代（D2预期+15%，D3则+30%同样可用）。点击Dialogue OFF→Read Great Works，截图；点击Dialogue AUTO→Read Great Works，截图。固定相同收藏与专家，不同时换政策/建筑。AUTO再点一次，理论和已配置档位不得相加。

比较作品Culture/Tourism实际数值，而非只看“已配置”。无其它作品倍率时AUTO应为OFF的1.15（D2）或1.30（D3）；若有原生倍率，不人工强算，回传两图与已有加成说明，Codex算差分。城市Culture可能另受宜居度/CultureIV专家百分比，报告分别保留作品与整城值。小数/同回合显示延迟先记录；必要时在同条件下OFF/AUTO各过一回合取得稳定值，注明回合变化。

## 2. 自动恢复与撤销（1张可合并，口述也可）

AUTO有效时保存重载，不先点击AUTO/OFF，直接Read Great Works应恢复相同D与已配置；然后移出唯一代表某时代的作品至其它城市，D应减1、bonus减15个百分点。若D2→D1，应配置0；移回恢复。或将总督调离使ACTIVE<4，配置归0，建立恢复后重新应用。选择方便的一种撤销方式，不必同时把所有组合重做。

此项主要看D/资格/配置与稳定后的原生变化，作品移动本身也改变基础收益，不能拿整城总量简单差值当成15%效果。

## 3. 主题化关系（现成收藏才做，2张；可后验）

已有主题化建筑的CultureIV城，保持收藏、D、专家/宜居度完全不动，只做Dialogue OFF/Read与AUTO/Read两图。报告主题化建筑应≥1，同时截作品Culture/Tourism。若主题化条件本身与跨时代不相容，可由同城其它建筑的作品贡献额外时代，不打散已主题化收藏。

不要为测试新开局或强凑主题化。Codex根据OFF/AUTO差值确认原生叠加；不把固定乘1.15当唯一PASS标准。如果出现意外结算顺序，先记录，不补偿。

## 判据与回传

PASS：D来源与去重正确；普通收藏原生两类百分比生效；同档不叠加，正常恢复/撤销；主题化只判原生结果已被观察，不假定乘法/加法。FAIL：配置存在但稳定后无相应真实变化、重复叠加、D/资格变化后仍保留旧效果。缺SQL/读取失败属于明确未完成，回传完整错误。

回传每组两张Read Great Works，注明OFF/AUTO、是否过回合、有哪些其它作品加成；恢复/撤销可口述。出错可附现有Database.log/Modding.log/Lua.log相关段，不改游戏日志配置。旧GW +2C按钮已隐藏，不再操作。
