# B064 独立备份与转移事件

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED（不等于正式继承）

完全退出应用后重启，确认B064.90；加载易主前仍有工业专业/投资/模板的存档。已在B063丢失记录的易主后存档不能凭空恢复，不用它作初始基线。不要求新游戏。时代对话25%无新增实机测试。

1. 选择原工业城，点Select shadow city，报告备份专业INDUSTRY、投资3、模板6（若选择其它城以它实际记录为准），错误=无。截图1。打开面板只选观察目标；加载已经自动备份，选择不是唯一备份触发器。
2. 赠送AI或转自由城市，说明方式。选择另一己方城市打开面板，点Read shadow / events，不再Select。截图2：备份仍3/6，新Owner/CityID可见；City Property可以为空。事件序号与参数应有新增，截全报告。
3. 保存该易主后状态，回主菜单重载。不要Select，直接Read shadow / events。截图3：备份专业、投资、模板仍完整；事件历史/观察UID保留。读取按钮不恢复城市专业/收益。

通过判据：三份报告的备份记录相同、无错误，转移端点及相关事件可识别，读档后仍读到。若备份完整但事件缺失，则只判数据保存通过，继续研究事件覆盖；不要把它判全继承通过。任一步报错/计数丢失只回传完整报告，停止，不反复重做或追加投资。Lua.log若方便可附，不强求手抄内部ID。最多这一组3图，不重复两种易主方式。
