# B057：明确整数Boost写入（同一存档三分支）

Document Owner: Codex
Build: P0-B-057.74 / modinfo74
Status: USER_GAME_TEST_REQUIRED

目的：只证明Specialization量化后写入整数2/4，实际增加相应百分点；不测试原生保留小数。需要零对照以消除既有基础Boost绝对偏差，不猜40%。

## 准备一次

使用原测试存档中测绘/法学尚未触发的存档S。优先此前同目标S：测绘600、法学2160；若已触发，使用更早存档或选另一未触发、不会因Boost直接完成的目标。不需要改变路线/等级。三分支都从S重载，均在同一回合、相同成本/初始进度触发同一个科技和同一个市政。不要在分支之间研究、换政策或升级总督。

面板顶部必须B057.74。新增实验覆盖本Mod的科研/文化网络Boost，不影响其它Mod来源。不必开贸易UI。若点击报告出现B055_DATABASE_MISSING并带BUILDING_SPC_B057名字、初始化错误、配置不等于要求值，先停止并回传报告；原存档可能未载入新实验定义，不盲测或要求现在自动换新局。

## 三分支（各一张最后Read boosts报告）

1. **T0 零对照**：载入S；点击`Boost test 0`；确认两类配置=0；点`Boost baseline`；用Cheat触发测绘/法学；点`Read boosts`，截图。
2. **T2 边界**：重新载入S；点`Raw 1.5 -> 2`；确认FinalRaw=1.5、量化2、两类配置2；再点一次同按钮，配置仍2；点`Boost baseline`，触发同两个目标，点`Read boosts`，截图。
3. **T4 非边界**：重新载入S；点`Raw 3.8 -> 4`；确认FinalRaw=3.8、量化4、两类配置4；重复点击一次仍4；点`Boost baseline`，触发同目标，点`Read boosts`，截图。最后点`Boost test 0`确认配置回0，再点`Restore auto Boost`退出实验，或直接重载S。无需额外截图，异常才回传。

## 判据（无需用户手算）

比较每个目标触发的delta，不比较城市每回合Science/Culture。测绘成本600：T2−T0应约+12，T4−T0约+24，T4−T2约+12进度。法学2160：对应约+43.2、+86.4、+43.2；原生最终进度取整可能有不足1点差异，记录实数交Codex算，不修复。以实际报告成本计算；若成本改变/跨回合/触发前已接近完成，记录为不够判定，不归因量化失败。

PASS：两个明确整数档实际差值吻合2/4个百分点，重复配置不叠加，零撤销。FAIL：在条件一致且未封顶时明显不吻合，或同一按钮重复叠加/清零不撤销。配置读数本身不等于实际效果通过。

失败回传：三张完整Read boosts（含FinalRaw/配置/状态/目标成本/pre/post/delta），说明哪一项不同、是否重复点击、存档加载方式。现有Database.log/Modding.log/Lua.log如有相关错误可附；不要为此修改游戏日志配置。若只缺载体，回传这一张错误即可。
