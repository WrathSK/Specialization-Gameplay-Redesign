# B054 自动标准化折扣

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED
Build: P0-B-054 / modinfo70

完全退出游戏后重启并加载原存档，无需新局。B053实验会自动清除；面板保留Purchase OFF供额外清理，BASE/ON暂隐藏。正常机制不需要打开P0、贸易或购买窗口来启动。新增Read discounts / Next discounts均只读。使用金币充足的测试存档，避免初测混入其它折扣和余额条件；不要求精确尾数，粮仓190已接受。

## B054-1 一条分发路线与基础模板组

选有效工业源S，已记录纪念碑（Read templates确认），ACTIVE1最容易对照，已有较高级也可直接测对应10/20/30/40。S→贸易中心T接入工业网络；选尚未接收工业网络、且未建粮仓的目的城R（已有存档没有合适城市时Cheat新建）。先在R金币购买页记录粮仓基价G0。建立T→R路线，先直接打开R购买页，检查价格下降，再Read discounts确认有效源、最高折扣和粮仓配置。不要点击任何实验ON。

PASS：只需源有纪念碑即可覆盖同一市中心BASIC组的粮仓，后台自动降价，报告配置为最高ACTIVE×10%；重复读取价格不继续下降。未启用的城墙不应得到本机制折扣；没有原生Gold购买资格的宗教/特色建筑不能因此解锁。当前没有天然双币建筑不要求再次准备Faith实验。

FAIL：报告后台一直待刷新、模板有却粮仓配置0/价格完全不变、无路线也凭历史来源保留效果，或反复读取叠加。先关闭重开购买页；若需要过回合才刷新，请说明，不把已配置当实际价格通过。

## B054-2 最高等级变化与模板来源独立

同一T另接入工业源H，ACTIVE高于S，例如S=1/H=3；H可以没有纪念碑等BASIC模板。R最高折扣应变为30%，模板仍可由S提供。不要求H重复建模板。再调离H的总督使其ACTIVE回落1，R应回到10%，不保留30%或累加成40%。Read discounts显示两个来源及ACTIVE；价格应朝相应方向变化。

PASS：模板与最高等级可以不同源；多个源不累加；降级自动回退。缺少合适第二源可先口述此项未测，不把单源结果外推多源。

## B054-3 撤销与重载

先在保持连接时保存、退出主菜单重载，直接打开R购买页：折扣仍自动恢复。再使R不再接收工业网络（优先现有Cheat能完成的删除唯一贸易中心/有效工业源；使用另存测试副本，不要误删主存档城市），只保留活着的R比较价格。重新打开购买页并Read discounts：对应匹配/配置清零，粮仓恢复G0。不能只移走S总督当作断网：ACTIVE1仍提供10%。如有多个源/中心，确保测试中没有其它有效接入路径。

PASS：重载不要求打开任何诊断或贸易UI即可恢复；真正断开后撤销。源被删除时不测试其账本是否保留；活源只断路的账本仍应保留，但不要求本批再测一遍B052存储。

## 回传

每项可口述PASS，给出折扣前后价格即可，接受原生尾数。失败只需R的Read discounts报告、Read network报告、当前粮仓购买价及操作说明。报DISCOUNT错误时回传Lua.log的[SPC][B054]段；数据库缺失另附Database.log错误段。无需整包数据库或大量截图。完整战争/自然商路结束、征服继承、余额不足、多人玩法未由这小批测试自动覆盖。
