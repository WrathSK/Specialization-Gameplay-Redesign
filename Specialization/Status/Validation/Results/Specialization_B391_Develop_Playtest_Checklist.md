# B391.418 — 新档阶段测试：需要刻意触发的情况

这次是develop中间版本检查，不是最终U5。用新档、单独存档槽；Cheat Panel可加速准备，但直接赋予结果不等于验证原生事件。照常开采集器；B271时序/事件顺序探针保持禁用，无需为本清单启用。全部为`USER_GAME_TEST_REQUIRED`。

每项留一个可返回的测试前存档。发生异常时记回合、城市、具体操作和预期/实际；保留日志，必要时截操作前后对照。不要通过重新派遣总督或读档先消掉异常再收集。

## 优先完成的八组

| 编号 | 刻意触发的操作 | 重点观察 |
|---|---|---|
| T1 同回合多次变化 | 文化城先投资到P4，再让1级总督到任，在同一回合连续升至4级；另一座无总督城用移民把P1投资至P2。科研、工业城各做一次专家增加→减少及总督调离→再派遣。 | 每次真实变化都更新；徽章/四格、机构列表、项目资格和实际效果一致；无总督的Potential边框也变化。不能靠重选/重新派遣总督才能恢复。 |
| T2 商业化真实入账 | 建立稳定有效的国内网络，开启实际收益大于0的商业化，正常结束3–5回合；至少一次修改配置后直接结束回合，不再开诊断或城市详情。另做一次正常存档、退出到菜单并重载。 | 商业化在应入账的回合持续生效，面板打开不是生效条件；读档不重复发金币。记录商业化应得值、总收入/支出和前后余额，不把金库总差额直接当成商业化收益。 |
| T3 网络增减与恢复 | 使用真实商人建立路线；中断一条路线或使商人被杀，再重新建立。分别调整来源城和接收城的ACTIVE。另删除一个战士、用完建造者次数、消耗投资移民作对照。 | 真实断连/已确认资格失效撤下适用收益，新收益在必要事实确认后出现；普通单位消失不应造成长期网络待确认或一轮明显卡顿。拓扑待确认本身不应反复拆建既有载体。 |
| T4 整回合项目和队列 | 认领、时代对话、工程传统研习各走一轮：先放在其他生产项目后方；移到当前唯一队列项；开始后追加再移除第二项；另做一次正常切换到其他项目。 | 队尾候选不冒充已开始计时；条件不满足时不提前完成；满足条件后同回合恢复显示，合法取消遵循各自规则；每轮只结算一次。留一个项目中途存档再读两次，检查不漏结算/不重复结算。 |
| T5 投资确认与结算 | 资本投资签一次，再不点击观察按钮/报价；发展投资签约后切城再返回。各做一次实际余额变化后确认、正常到期，以及合同中途保存读档。具备条件时在同一对象叠加标准化与发展投资。 | 不出现无故“—”/报价失效；实际余额变化后按新事实核对；每笔只扣一次，到期只结算一次；合同卡片/实际扣款连续；可叠加的产出相加，不互相覆盖。 |
| T6 保存、计龄和重配 | 科研IV、商业IV各正常计龄，记录数值后手动存档和自动存档分别重载；重载后正常走一个完整回合。另让城市进入“重配中（REALLOCATING）”，存档重载后再完成配置。 | 加载本身不补算年龄/收益、不丢历史；可靠完整回合正常计龄；机构/项目/按钮无需反复重选才出现；重配中的旧收益不复活，配置后正确恢复。 |
| T7 真实掠夺与修复 | 科研/工业专业城的真实锚点区域或相关建筑被掠夺，再通过正常修复恢复；若方便，扩到9城以上再测一次。洪水可作附加场景。 | 真实依赖失效时按能力规则撤下效果，修复在同回合正确刷新；隐藏载体不应自身进入被掠夺状态，日志不应有CARRIER_PILLAGED_PRESENT。9城以上覆盖较大帝国的缓存边界。 |
| T8 操作后不靠窗口、空闲和过回合 | 加/减专家、升总督、完成区域/建筑后不打开诊断，观察城市收益，再开面板核对；随后空闲约1分钟并正常走3–5回合，覆盖AI行动阶段。 | 业务效果不依赖打开窗口；没有持续待确认、每次界面刷新都重算的卡顿或日志风暴。记录哪一阶段最卡；此版本仍有未退出旧探针，不据此宣称最终性能完成。 |

## 两项另存档观察，不作为本版本必过门槛

1. **失城→存档重载→夺回。** 只观察现有支持的失去/夺回路径：旧收益撤下、已有历史/合同不错误复活、不重新支付；不据此扩展尚未定案的城市易主玩法。记录失城瞬间是否有明显停顿。
2. **两工业城市同级施工队同回合完成。** 原生唯一归属证据问题仍开放；若专门测请另存档，记录两城项目、实际生成单位和是否HELD。常规能力测试先错开完成回合，不把已知开放项误当本次新回归。施工队的实际使用另测一次保存读档后不重复执行。

## 本轮不要求人为制造

不修改存档/Property来伪造UNKNOWN、子记录损坏或资金错误；这些先由本地故障注入验证。商业/文化网络的冷加载逐来源保留尚未接入；若自然遇到先留证据，不能标为已修复或用一次普通读档通过替代。

本清单只覆盖需要刻意触发的时序/恢复/一致性边界；各能力数值的全面Cheat Panel检查另行保留。测试资料中请区分准备使用了Cheat与实际触发采用的原生操作。
