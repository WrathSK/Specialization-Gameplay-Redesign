## B055-1 — 实际Boost与小数（同一套城市，四个档位）

使用科研/文化来源接入同一贸易中心（首都最方便），先不由中心向其它城市分发；两个网络报告均应N=1。首都科研self也可作为科研来源。来源ACTIVE每档均可用投资+总督依次升1→2→3→4；不要只升Potential。无需建立四套城市。

每档：
1. 选任意己方城，点 **Read boosts**：科研→鼓舞、文化→尤里卡方向正确，ACTIVE=当前档、N=1。配置应依次1.1、2.2、3.3、4.5。
2. 点 **Boost baseline**，同回合分别触发一次未触发的尤里卡和鼓舞（共两项），再点 **Read boosts**。报告自动列出各项成本、前后进度、增量及总百分比。
3. 不跨回合研究，不改变政策或同时获取大科学家/大图书馆。下一档选择另两项尚未Boost的目标，重新记基线。

PASS：两种方向额外Boost实际生效；等级提高对应更大加成。底层舍去小数也按用户授权接受，记录原数值不要求补偿。不能只凭“配置=预期”判定实际PASS。总百分比包括游戏原有Boost；不要假定固定40%。若不清楚基础比例，回传报告即可由Codex结合原有修正计算；必要时才补一个同条件未接入对照。

FAIL：实际进度没有任何网络增量、方向颠倒、重复刷新让同档收益累加。若目标已接近完成，增量被剩余需求限制属于不适合本测试的样本，换一个目标。

回传：每档报告中的两行cost/前后/Δ（截图或口述均可）；不需要手写city ID。若有错误，附顶部状态和错误行。

## B055-2 — 新Boost的撤销/重建（不重复测商路分页）

在上述同一存档：
1. 贸易中心新增一条到另一己方城的分发路线。Read boosts中对应N从1变2；ACTIVE4时配置应为`4.5×sqrt(2)≈6.363961`。
2. 若已有不同等级同类源，调走最高源总督：L应回退至剩余最高ACTIVE，而非清空其它有效来源，也不按源数叠加。没有现成多源就只测已有源降级，无需额外搭建。
3. 保存读档，不先打开贸易UI；Read boosts应恢复同一L/N/配置，无重复叠加。记新基线，再触发一项尚未Boost目标，观察实际增量与当前较低等级一致。

PASS：配置幂等恢复、真实新Boost与当前档位一致；此前已触发的科技/市政进度不被重算。FAIL：留着旧高档奖励、重载后双份、必须先打开贸易窗口才初始化。

回传：读档后报告；若撤销实际失败，附触发前后报告。不需要重做全部战争/商人死亡边界。

## B055-3 — 一件著作，比较“作品加成”和“城市补贴”

选一座已有槽位的测试城（文化专业最方便），放入**恰好一件著作**。保持专家、宜居度、政策等不变。不要求新局/新增专业投资。

1. **GW OFF** → **Read Great Works**，记录作品文化、作品旅游业、整城文化。
2. **GW per work +2C** → Read Great Works；再点一次同按钮 →读取。
3. **GW city +2C** →读取；最后 **GW OFF** →读取。

PASS：OBJECT模式作品文化增加（原生作品倍率可能影响具体增量）；CITY模式作品文化回到原值，而整城获得固定基础+2文化再吃城市倍率；重复不叠加，OFF恢复。两模式本项目均未配置Tourism加成，记录旅游业是否变化，不预设所有HD联动结论。原生UI可能延迟，必要时过一回合复读，但不要改变其它变量。

这是手动接口实验，CITY并不按作品数量累加，不是正式时代保值；不要把两个实验系数当最终GW曲线。

回传：OFF / OBJECT / CITY的三组读数即可。若城市倍率不清楚，只提供读数，不必手算。
