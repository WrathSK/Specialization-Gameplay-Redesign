# B063 城市继承只读观察

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED（待用户实机，未实现正式继承）

完全退出游戏后重新启动，加载已有存档，面板B063.89。新增Lua需要刷新组件列表，不要求新游戏。

1. 另存测试档；选择非首都Industry专业城，优先已有一次投资和一个模板的城市。点击Record inheritance，截一张完整报告。
2. 在同次加载中用赠送/交易、Cheat转交或实际征服让该城归另一玩家。不要读档或再次Record。选自己另一座城市打开P0，点击Read inheritance，截一张。告知具体转交方式；赠送/Cheat不等同已测军事征服。

只观察两张报告。成功判据：Owner由自己变为新玩家，五项原始Property逐项报告保留/变化/消失，能读投资/模板数；不是要求现有正式收益跨Owner正常。若Property消失，属于关键研究结果，不需要自行补投资或重建模板。若读数无法生成，回传完整错误报告；不要反复操作。基线是本次加载内存，读档后必须重新Record才有比较，不能据基线消失判断永久记录丢失。

可选：方便取回城市时再Read一次；不是必需。观察按钮不修改身份/Potential/收益，不保证现有机制已适配新Owner。
