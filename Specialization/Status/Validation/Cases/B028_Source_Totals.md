# B028：只读城市产出（一个测试）

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED

使用现有测试存档，退出主菜单重新加载，确认面板B028。无需升级专业、重开局或打开贸易总览。

1. 选已有科研城市，点击Read source totals。截图保留探针及右下城市产出栏。SCIENCE/CULTURE/PRODUCTION应分别对应该城科技/文化/生产力每回合总产出；不要比较屏幕左上全国总数。探针显示六位小数，UI可能只显示一位，允许显示舍入/截断造成的小于0.1差别。
2. 在市民管理中移出或放入一名学院工作专家，确保城市科技显示确有变化；重新点击Read source totals并截图。预期重新读取后的科技与当前城市值一致，无UNKNOWN。若调配后UI总量恰好未变，换一次能改变科技的分配，不必人工计算差值。

PASS：三项有数值、与城市面板在显示精度内一致，改变专家后新数值同步。FAIL：UNKNOWN/报错、错误城市、明显差值或仍停留旧值。回传前后两图即可；失败保留存档，不要求复制剪贴板。未确认的单项可以单独登记，不能以部分成功代替三项读取。

这只是直接getter读数，不验证纯本地剥离、商业IV资格/发放、20%最终增量或网络来源选择。旧可读性与断路测试保持延后。
