# B050：固定半点收益，两项测试

Document Owner: Codex
Status: USER_GAME_TEST_REQUIRED

使用现有测试存档即可，退出主菜单重载新包，面板P0-B-050。选一座便于控制人口、没有正在变化的专家/总督/政策的城市；不需要工业网络、Lv4或新局。操作为只在所选城市加候选0.5科技和0.5生产力，结束请Half OFF。

## 1. 人口3，检验每人口系数与整数扣除组合

用Cheat调整至3人口，等待城市产出稳定；固定人口分配，不换政策。先点Half OFF，再Read half test记基准。点Half +0.5 ON，再Read half test；重复ON不应继续增长。然后Half OFF，再Read half test。

PASS：ON后原生科技/生产力均增加0.5基础值，OFF回到本次同人口基准；若有宜居度或其它百分比，最终值按原生倍率变化，截图可由Codex验算。不能只看“配置=0.5”判断通过。若原生读数需要过回合才能刷新，允许过回合，但保持人口和工作分配，说明发生延迟。不得把其它人口/建造/政策变化算入差额。

## 2. 人口4，检验更小系数仍保留半点

保持实验OFF，将同城调至4人口、产出稳定，重新Read记基准；ON→Read→OFF→Read。预期仍增加0.5基础科技/生产力并完整回落，不与人口3时的总量直接相减。人口4使用0.125×4，人口3使用0.5×3−1，因此这是两个不同原生精度/组合检查。

FAIL：只增加0/整数、不按倍率解释的其它数、重复ON累加、OFF不撤销或报错。回传各人口下OFF基准/ON/OFF报告（或口述精确Science/Production），异常附城市原生yield tooltip供倍率核对；Lua.log可回传[SPC][B050]段。测试完保持OFF。

没有单独派投资/Crew/B049复测。通过本批只证明半点组合，不证明任意小数、整个Lv4或标准化折扣。
