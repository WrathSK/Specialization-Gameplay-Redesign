# B031：现存商路断开后的网络撤销

Document Owner: Codex
State: USER_GAME_TEST_REQUIRED

一个案例，通常两张概况图；沿用此前网络测试存档，不要求新局。请先另存测试副本，因为以下使用Cheat Panel删除城市。

选择贸易中心H和目的城市D：H已经接入科研或文化来源S，并有H→D商路；D不是首都/贸易中心、也不是该网络来源，且没有另一条使它接收该类型网络的路线。最好只有H→D这一条相关路线，避免多个城市一起变化。H和S始终保留。没有合适旧局时先反馈，不为本案重建复杂帝国。

1. 加载后确认P0-B-031。无需打开原版/BTS贸易窗口。选择H，点“网络概况 (Game)”截图①，关注该网络全国接收城市数和本中心接入来源数。可点“网络明细 / 下一页”检查城市名称与H→D方向，不需要截图所有页。
2. 用Cheat Panel删除D，待该操作结束后选H，点概况截图②。不要点击其它读取路线按钮作为初始化前提。预期：相关网络全国接收城市数减少1，本中心接入来源数不变、H本城接收仍“是”，有效分发路线数减少1。短暂“待刷新”不算失败；后台刷新后再次读取应恢复正常。如持续待刷新，可只过1回合再读一次并回报。

PASS：正常报告恢复，旧D不再计入全国接收集合，中心直连仍保持，明细不再列H→D。FAIL：操作/后台刷新及1回合后仍有旧路线/旧N，或中心无故失去保留的直接来源，或错误/持续待刷新。若还有其它来源/路线受删城影响，保留截图据实际拓扑判断，不机械要求-1。

失败回传最后一张概况、相关明细或完整错误；保留测试前后存档，若生成日志则保留Lua.log/Database.log/Modding.log。无需手抄ID或自己计算产出。

这是“目的城市删除造成路线端点失效”的撤销案例，不等价于自然商路到期、战争、商人被掠夺或主动取消；那些边界保持未测，不在本批增加测试。没有新收益或高级专业能力。
