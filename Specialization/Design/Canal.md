# 运河辅助系统

运河的未来辅助效果按城市当前专业，把相邻已改良地块与专业发展联系起来。它不是独立的四级新专业，也不进入当前实施。

## 相邻改良收益

设L为本城当前ACTIVE等级，每个符合条件的相邻已改良地块得到：

| 城市专业 | 每级L的额外产出 |
|---|---|
| 科研 | +1科技 |
| 文化 | +1文化 |
| 工业、军事 | +1生产力 |
| 商业、港口 | +3金币 |
| 景观、政府、外交 | +1食物 |
| 宗教 | +1信仰 |

这里采用1科技＝1文化＝1生产力＝1食物＝1信仰＝3金币的本能力换算；与Shared产出份额一致不代表所有机制的普遍市场兑换率，更不自动改掉各专业独有映射。

## 与HD及其它设计的边界

原则上替代HD原相邻改良+6金币，不叠加；原运河贸易／产品机制保留。

多个运河重复邻接、跨城市地块归属以及社区身份对应什么产出尚未说明，保持待定。港口旧驻扎训练已由D0037退出；Canal对新海上连通拓扑的作用见[港口](Harbor.md)，尚待调查。没有新的机构／界面合同，不自行补齐。
