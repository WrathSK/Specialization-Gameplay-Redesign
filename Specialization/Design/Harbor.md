# 港口专业：海运商业与海军的完整双线

港口利用海洋连接组织船舶、货物、市场与舰队。一座成熟港口同时拥有**完整的海运商业体系和完整的海军体系**，不是各取一半，也不是让玩家在商业港与军港之间二选一。

商业线从国内港际联运出发，开拓不同海外市场，把腹地的基础设施价值转成出口，再将外国文明最具代表性的产品带回来。长期真实经营还可以形成永久航线容量。海军线则从正式船员编制发展到综合训练、远洋保障、老兵传授、战斗领悟与地方海军传统。

这是**已接受的未来设计基线**，不属于当前v0.1四专业实施范围。机制、名字与数值分别记录成熟度；下文“强候选”“暂定”“可冻结”都不等于名称已经锁定。实际实现与验证只查[Status](../Status/Specialization_P0_Status.md)。

## 等级、机构与能力

一、二级各有一个共同机构；三、四级分别有商业与海军两个同级机构，双方同时成立和成长。机构存在依[Shared](Shared.md)的身份/Potential规则，能力按ACTIVE资格；这里的分叉是制度分工，不是选项。

| 等级／分支 | 机构与命名状态 | 本阶段内容 |
|---|---|---|
| I 共同 | 码头同业公会（占位） | 基础Harbor专业支持，不强造独立能力名 |
| II 共同 | 船政局（强冻结候选） | 船员编制：住房与实际工作专家的基础大海军统帅点数 |
| III 商业 | 远洋海贸局（占位） | 港际联运、通商万邦（均强候选名） |
| III 海军 | 远洋防务局（占位） | 综合训练、远洋勤务（均可冻结名） |
| IV 商业 | 跨洋通商枢纽（占位） | 集货出洋、舶来采长、久航成业（均暂定名） |
| IV 海军 | 战略海军枢纽（占位） | 舰阵传授、海略传承（强候选名）；怒海真知（可冻结名） |

“船员编制”为可冻结名称。除船政局外，本轮给出的机构名均为占位名；不将“可冻结”自动改成LOCKED。

## 一、二级：基础支持与船员编制

一级维持已有Harbor基础专业支持。当前来源没有补定一套新的支持数值，因此不从其它专业搬入3粮3生产力等公式。

二级**船员编制**镜像军事的**行伍编制**：合格Harbor本体及普通建筑提供住房，实际工作的港口专家提供基础大海军统帅点数。住房沿Tier存在性的镜像思路，不按加权D计算；空专家槽不产生点数。具体Harbor住房与点数数值留待平衡，不把军事数值自动写成港口定值。

它表达港口开始形成正式舰员、船员和海军人才编制，而不再只有普通码头工人与水手。旧二级每专家+15%正常战斗经验已退出。

旧来源曾笼统提及大商人点数与海洋改良收益，但没有等级、系数或完整合同。本轮没有把这些文字补成额外确定能力；其未被新基线明确分配的范围留待澄清。

## 商业三级：从港际物产到国际市场

### 港际联运

ACTIVE III及以上的港口专业城，读取**同一海上连通网络内，己方其它拥有合格Harbor的城市所拥有的海洋资源**。供应城市不必专业化：普通港口可以成为支线港，高级专业港成为枢纽港。

本地海洋资源维持正常Harbor资源基础相邻价值。此前已接受的“本城全部海洋资源，不限紧邻Harbor”范围没有被本轮明确缩小；海洋资源的归属及改良资格仍待细化。远端合格海洋资源在第一轮平衡测试中**优先尝试+1**，这不是最终数值。

能力只读原始资源事实，不把本网络生成的相邻或产出再次作为输入。它让分散的海洋物产进入共同港口经济体系，而不是递归汇聚其它港口的最终收益。“合格Harbor”与海上连通、Canal的具体判定仍待定义或调查。

### 通商万邦

对于本港，每与一个不同外国文明维持至少一条有效国际海上贸易关系，就多计一个市场。设不同文明数为N，本城出发的全部合格国际海上商路获得：

`倍率 = 1 + K × N`

K未定；当前保持线性，不预设递减。与同一文明的第二条、第三条路线不增加N，但合格出发路线仍受倍率作用。

第一条通往新文明的路线打开市场，重复路线则深耕已有市场。为新市场牺牲一条基础收益更好的路线是允许的建设取舍；只有数值导致任何低价值市场都必开时，才需要调整K。

**受益路线明确是本城出发的路线**；用于计N的外国关系是否接受入站路线，以及外国文明的具体类别范围，尚未明确，不能套用商业专业或共同网络方向来补齐。

## 商业四级：出口、特色进口与航运产业

### 集货出洋：港口腹地与出口价值

四级港口形成自己的腹地：己方城市拥有合格Harbor且与本港海上可达，就自动接入。不能这样自动接入的己方城市，必须以有效国内商路连接本港。因此港口城市天然容易接入，内陆城市也能参加，但要付出商路容量。国内连接的具体方向尚未指定。

腹地接入城市中的合格区域贡献**基础相邻值（Base Adjacency）**。固定依赖方向是：

`基础相邻 → 出口价值 → 本港出发的国际海上商路`

不读取城市总产出、Actual Yield、百分比修正、本能力出口收益、港口网络派生收益或其它递归衍生值。旧“本港自身用更高比例Actual/local”的例外不再保留。

`ExportValue = f(Σ BaseAdjacency)`

最简单原型可以尝试`K_E × Σ BaseAdjacency`，但转换曲线没有冻结。低比例线性、分段递减或次线性均可以在平衡阶段比较。哪些区域合格、如何汇总不同产出/负相邻、本港自身的接入处理、转换成哪些收益，仍须明确。

出口价值加入**每一条本港出发的合格国际海上商路**，之后再与三级市场广度倍率组合。原生目的地价值表达“对方城市有多值得做生意”；出口价值表达“我有多少货要卖出去”。成熟港口的出口价值高于原生目的地价值并不自动构成错误：它可以是大规模出口导向，甚至类似倾销的市场扩张。

### 舶来采长：万国所长，由海而来

每个通过至少一条有效国际海上商路与本港保持联系的外国文明，最多提供**一份特殊进口供应**。同文明多条路线不提供多份；它也不是固定的一种奢侈品。

供应类型取决于该文明当前相对于世界最突出的文明级领域。候选指标为科技、文化、金币、信仰、外交支持和军事力量。生产力暂不纳入，因为当前不假设已有同样清楚可比的文明级总生产力接口；这不是宣称引擎绝对无法提供。

供应按关系生命周期锁定：

1. 与该文明的合格关系从0变为至少1时，读取其指标，与当前世界其它主要文明比较，选出代表领域并锁定供应类型。
2. 只要至少一条合格路线还在，类型保持不变，不随每回合排名刷新。
3. 最后一条关系断开，供应消失；未来重新0→1时按新格局重新判定。

分类尚未冻结。一个候选是`Score_y = AI_y / Median_y`，比较相对世界中位数的突出程度，避免直接比较不同单位的绝对数值；中位数比均值更能抵抗极端值，比例比纯排名保留领先幅度。但指标可比性、零值/缺值/并列和比较文明集合等仍需调查，不能将此候选写成已采用算法。

不另加时代锁或anti-reroll。设计理由是普通进行中的商路不能零成本随意取消，关系归零通常伴随自然结束不续、战争、掠夺、商人损失或容量变化等实际成本。各类供应的具体效果尚未决定；叙事可以是商品、器物、技术产品、文化产品、宗教用品或军需，不是仅给奢侈品换颜色。

### 久航成业：长期经营形成永久容量

高级港口要为市场、腹地、进口与出口支付商路容量，四级投资又意味着消耗额外开拓者/Potential、放弃部分横向扩张。因此，长期实际经营可以让港口逐渐形成自己的航运能力。

本港当回合同时满足**ACTIVE IV**及**至少一条有效海上商路正在运行**，经营时间就累计+1。国内、国际海上路线都有效；1条或8条都只加1，大帝国不能一次投入很多商人就购买长期历史。这里积累的是港务和航运经营，不只是国际风险。入站路线是否满足“本港运行”的资格仍待明确。

不按商路完成次数累计。短、中、远路线周期不同，按次数会奖励短途刷路线，反而惩罚远洋经营。

达到递增的离散经营时间门槛后，每个里程碑永久获得+1商路容量。原型候选为：

`T_n = C × n × (n + 1) / 2`

以C=6为例，门槛是6、18、36、60、90、126……。**曲线和C都没有冻结**，后段可能偏慢，之后可以调整系数、增长速度或更换曲线，不能把这个例子当正式默认。

失去ACTIVE IV后，经营进度暂停而不清零。已经获得的容量永久保留，不因总督调走或ACTIVE IV暂时失效而撤回。它代表航路经验、商人/船东/航运家族、信用、代理、保险、仓储、船队组织与港务制度；总督转去培养另一港口，是允许的长期制度扩散。

易主、转专业、城市摧毁时这些资产如何归属，本次尚未定义；不能从“总督调走仍保留”推导统一的永久成果继承规则。

## 海军三级：综合训练与远洋勤务

海军能力明确镜像**当前军事体系**，不沿用旧Harbor军事扩展。共同出生授予、合并与经验口径见下节；军事自身数值未被修改。

**综合训练**读取学院、剧院、工业区、商业中心、圣地五领域。Breadth→Quality：合格普通T1建筑的实际存在，使新海军单位获得综合训练优势；裸区域、D>0或仅有高阶建筑不能替代T1。Depth→Efficiency：同样五领域的绝对基础设施深度D提高本城训练效率，T1-only无深度收益，T2阶段开始贡献，不要求100%建满或D10。

普通建筑、特色替代、免费普通建筑及单领域最高单区域D沿[Shared](Shared.md)；不加入港口或其它领域。横向铺领域与纵向深化基础设施仍是不同投入路线。Harbor具体转换数值TBD，不将军事+1/最多+5自动宣称为港口最终定值；训练效率的汇总方式、曲线、精确起点、上限、速度与购买适用继续未定。

**远洋勤务**镜像**战地勤务**，形成正式支援/补给体系，为长期舰队行动服务。部分持续战略资源维护可以由金币承担；训练、购买、升级的一次性战略资源成本不变。

它沿用军事“有生产成本的实体支援、可见1:1护送/关联”的方向，尚未确定具体补给船、资源覆盖、版本解锁或金额。铀边界继续未定；没有采用额外抽象替代系统，也不因护送关系自动声称多占一块地格。相关绑定、死亡、升级、资源扣除时序与保存接口须技术验证。

## 海军四级：传授、领悟与地方传统

### 单位授予与保存口径

当前Military镜像覆盖合格海军战斗单位的生产、金币/信仰购买；免费、征召、复制、俘获仅在能可靠确认来源属于训练城市时计入，否则排除。不能由当前位置或最近港口猜来源，也不将民用船自动算作海军战斗单位。具体海军类别及取得来源接口仍需核对。

在合格取得时，将当时城市ACTIVE能力资格、实际工作的Harbor专家数`E_birth`、适用地方传统加成作为单位永久训练快照。此后城市ACTIVE、专家数或传统变化不反向重算已有单位；实际晋升P和邻近导师仍读取战斗当时事实。合并时，同一能力效果取组成单位最高值，不相加、不平均；不同能力分别保留。升级、复合参数合并的技术验证和单位易主Legacy仍未完成。

这项永久快照只用于授予单位的质量/经验能力；本城训练效率不是出生后随单位携带的收益。

### 舰阵传授

携带传授权利的己方合格海军单位在实际战斗时，可以从相邻一格、同PromotionClass、实际晋升更高的己方海军单位获得：

`额外传授XP = max(0, floor((导师晋升数 − 作战单位晋升数) / 2))`

多导师取最高晋升，不叠加；中等晋升单位也能受益，不只限零晋升新兵。导师不必是旗舰。“舰阵”表达舰队编组/海上阵列。

这是独立额外经验，不受正常战斗经验倍率放大，不受E限制，也不另加人为上限；不绑定驻扎训练。传统增强按取得时快照，具体增量待平衡。精确战斗事件、位置与特殊战斗分类仍需调查。

### 怒海真知

镜像沙场领悟：

`额外领悟XP = min(E_birth, floor(P_current / 2))`

E是取得时锁定的实际工作Harbor专家数；P是战斗时实际晋升，包括合法编队继承，不是经验等级。它表达舰员训练基础与自身战斗经验结合，不是在单位刚取得时一次发完XP，也不再持续查询来源城专家。

额外经验独立于普通战斗XP，不修改普通XP上限；旧讨论的8点上限、军营E≤4不是新港口的通用约束。该能力在四级，旧三级动态E领悟退出；海军数值平衡仍待验证。

### 海略传承

大海军统帅可以在四级港口放弃原本的一次性退休效果，消耗自身、永久制度化为**该城的地方海军传统**，不同时领取原生退休奖励。它是本地资产，不是全国加成或自动Network载荷。

后续在此取得的合格海军单位继承传统带来的出生战力、传授或领悟增强；既有单位不追溯升级。沿当前军事方向使用有限离散阶段，每一阶段增强三者之一；“约六阶段”不是锁定港口数量，门槛、顺序、增量都未定。不额外加入不同年代统帅要求。

它沉淀海军战略、舰队训练、名将经验和军港文化。地方传统在转专业/易主后的规则仍须单独定义，不能与已经授予单位的永久buff混为一谈。

## 网络与其它专业的边界

Harbor**不设额外独立Network Ability**。商业线已经包含海上连通、资源网络、腹地、国内接入、国际商路、外国市场与进口供应；不为凑其它专业模板而再加一种载荷。海军也不镜像统一动员或Commander City，不塑造成全国唯一海军司令城。

| 系统 | 资格／输入 | 作用与明确边界 |
|---|---|---|
| 港际联运 | 同海上网络、其它己方合格Harbor及原始海洋资源 | 非专业供应港也参加；不递归读网络产出 |
| 港口腹地 | 己方合格Harbor海上可达，或有效国内商路连接 | 读Base Adjacency；不使用旧本港Actual例外 |
| 通商万邦 | 不同外国文明有效国际海上关系 | 按文明去重；奖励本港出发的合格国际海上路线 |
| 舶来采长 | 每外国文明至少一条合格国际海上关系 | 每文明最多一份，0→1锁类型、1→0移除 |
| 久航成业 | ACTIVE IV且本港有有效海上商路 | 国内/国际均可；每回合最多+1经营时间 |
| [共同网络](Network.md) | 独立的来源／中心／分发／接收合同 | 不用共同网络模板补齐Harbor未定方向，也不改写其它专业连接资格 |

[Canal](Canal.md)既有辅助相邻设计、[联盟外交任务](DiplomaticMissions.md)中的海运贸易协定仍是各自的未来设计；本轮不将其变成港口新能力。Canal如何改变实际海上连通拓扑另待调查。

## 展示与尚未定稿事项

展示需要容纳三级和四级各两个同级机构条目，明确两线同时拥有；不硬编码严格四行，不将分叉画成二选一。机构名与能力名保留上述成熟度；本轮没有新定图标、面板或操作入口，也没有实施UI。

平衡待定：远端资源贡献（首测倾向+1）、K、出口函数与收益分配、进口各类型效果、经营里程碑曲线/速度，以及海军住房/GPP/训练/后勤/传统相关未定数值。候选算法、C=6与线性出口原型不作为默认配置。

技术调查：海上商路可靠识别、海上连通网络及缓存/Canal、六项文明指标接口与分类算法、关系0→1/1→0事件、永久航线容量接口、海军支援和单位快照/编队/战斗接口。技术未知不等于原生不可能，也不允许为实现便利改玩法。

未决设计边界包括合格Harbor/资源口径、关系与国内连接方向、外国文明范围、出口区域/本港/不同产出汇总、旧未定Merchant文字，以及资产跨身份/owner/城市消失归属。这些不阻止保存当前基线，但后续依赖它们的实施必须先明确。
